Your DAX is business logic

      
No data leaves, but your measure formulas and object names do. That is intellectual property. For client-owned models, point the tool at a self-hosted model — a settings change, not a rebuild.

    

    

      
The AI is genuinely optional

      
With no API key configured, the outbound call cannot happen — the code throws before a packet is ever built. Everything in offline mode keeps working regardless.

    

    

      
Structural, not a policy

      
The AI path reads the metadata endpoint. Row data lives on a separate endpoint it never calls. Privacy here is enforced by wiring, not by a filter someone must remember to apply.
